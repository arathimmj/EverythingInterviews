COMPUTE IN THE CLOUD
	Amazon Elastic Compute Cloud - EC2 - Compute as a service model
		- raw compute capacity to host your apps and provide the compute power that the business needs
		- Flexible, cost-effective and quick
		- Request the EC2 instances u want. Stop or terminate the EC2 instances
		- Pay for only running instances. Not stopped or terminated ones
		- EC2 are VMs. VMs share an underlying physical host machine with multiple other instances this concept is calles multi-tenancy. in a multitenant env, u need to make sure that each VM is isolated from eo. but is still able to share resources provided by the host. this job of resource sharing and isolation is being done by a pieec of s/w called a hypervisor which runs on the host machine. in EC2, aws manages the underlying host, the hypervisor and the isolation for each instance.
		- When u provision an EC2 instance, u can shoose the OS. U can configure the s/w running on the instance.
		- EC2 instances are resizable. U can give it more memory or CPU(vertical scaling). U also control the networking aspect of the instance. U decide what type of request make it to the server. Or if they are publically or privately accessible.
	Types of EC2 instances
		- Instance types are grouped under instance families based on CPU, memory, storage and networking capacity
		- The instance families are:
			* General purpose : good balance of compute, memory and networking resources. Best for: Web services and code repositories
			* Compute optimised : ideal for compute intensive tasks. Eg gaming services, HPC, ML tasks and even scientific modelling
			* Memory optimised : ideal for memory intensive tasks. Fast performance for workloads that process large datasetsin memory
			* Accelerated computing : floating pt number calc, graphics processing or data pattern matching. Use hardware accelerator. Co-processors that perform functions mode efficiently than is possible on s/w running on CPUs
			* Storage optimised : Ideal for workloads that require high performance for locally stored data
